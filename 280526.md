# Perbaikan Print Layout — Invoice Customer Detail

**File:** `app\(dashboard)\hq\invoice-customer\[id]\page.tsx`

---

## 1. Fix Print CSS — Color Override Terlalu Agresif

**Lokasi:** Baris ~780 (`style jsx global` → `@media print` → `* { ... }`)

**Masalah:** `* { color: #000000 !important }` menimpa semua teks, termasuk status badge (sent=blue, paid=purple) dan header.

**Perbaikan:**
- Hapus `* { color: #000000 !important; background-color: transparent !important; ... }`
- Ganti dengan selektor spesifik:
  ```css
  .print-only,
  .print-only * {
    color: #000000 !important;
    background-color: transparent !important;
    box-shadow: none !important;
    text-shadow: none !important;
  }
  /* Khusus border tetap hitam */
  .print-only * {
    border-color: #000000 !important;
  }
  ```

## 2. Fix White Screen Saat Print

**Lokasi:** Baris ~724-791 (style jsx global)

**Masalah:** Saat `window.print()` dipanggil, yang keluar putih/blank. Kemungkinan CSS `body > :not(.print-only)` ikut menyembunyikan print content karena print content bukan anak langsung `body`.

**Perbaikan:**
- Hapus selektor `body > :not(.print-only) { display: none !important; }`
- Ganti dengan:
  ```css
  body > :not(:has(.print-only)) {
    display: none !important;
  }
  /* Atau pendekatan class-based */
  .print-hidden {
    display: none !important;
  }
  ```
- Pastikan wrapper layout dashboard diberi class `print-hidden`

---

## 3. Fix `table-layout: fixed` — Width Persentase Kaku

**Lokasi:** Baris ~766-776

**Masalah:** `table-layout: fixed` + width: 55%, 20%, 15%, 10% memaksa konten panjang wrap ke bawah, tidak bisa melebar.

**Perbaikan:**
```css
table.print-table {
  width: 100% !important;
  border-collapse: collapse !important;
}

table.print-table th,
table.print-table td {
  padding: 2mm 3mm;
  text-align: left;
  vertical-align: top;
  border: 1px solid #000;
}

table.print-table th:first-child { width: auto; }  /* deskripsi — fleksibel */
table.print-table th:nth-child(2) { width: 12mm; }  /* qty — tetap */
table.print-table th:nth-child(3) { width: 25mm; }  /* harga — tetap */
table.print-table th:nth-child(4) { width: 30mm; }  /* jumlah — tetap */
```

**Jangan pakai `!important` di kolom width — cukup specificity. Hapus `table-layout: fixed`.**

## 4. Ganti Layout flex/grid → Native CSS Table-cell

**Lokasi:** Baris ~797-1126 (seluruh print layout JSX)

**Masalah:** Browser (terutama Chromium) gagal menghitung tinggi kertas (`@page { size: A4 }`) jika ada elemen Tailwind `flex` atau `grid` di dalam print layout. Akibatnya page break tidak akurat atau halaman kedua tidak muncul.

**Perbaikan:**
- Di section **Header** (baris ~809-875): ganti `display: flex` → `display: table`, `width: 100%`
  ```jsx
  <div style={{ display: "table", width: "100%", marginBottom: "12mm", borderBottom: "2px solid #000", paddingBottom: "8mm" }}>
    <div style={{ display: "table-cell", verticalAlign: "top" }}>
      {/* logo + nama perusahaan */}
    </div>
    <div style={{ display: "table-cell", verticalAlign: "top", textAlign: "right" }}>
      {/* INVOICE + nomor */}
    </div>
  </div>
  ```

- Di section **Invoice Details** (baris ~878-946): ganti `display: grid; grid-template-columns: 1fr 1fr` → `display: table; width: 100%`
  ```jsx
  <div style={{ display: "table", width: "100%", marginBottom: "10mm" }}>
    {/* setiap kolom: display: table-cell; width: 50% */}
  </div>
  ```

- Di section **Bill To** (baris ~948-1018): sama, ganti grid → table.

- Gunakan inline style saja, JANGAN pakai Tailwind classes (`flex`, `grid`, `flex-col`).

## 5. Tambah Selektor CSS untuk Sembunyikan Elemen Wrapper Next.js

**Lokasi:** Baris ~724-755

**Masalah:** Saat print, masih muncul "SYSTEM ONLINE" header atau wrapper Next.js (`#__next`, layout dashboard).

**Perbaikan:** Tambahkan selektor berikut di dalam `@media print`:
```css
/* Sembunyikan semua wrapper aplikasi */
#__next,
[data-nextjs-root],
[data-rht-toaster],
.next-error-boundary,
header,
nav,
footer,
aside,
button:not(.print-only button),
.system-online-header,
#system-header,
[class*="sidebar"],
[class*="navbar"],
[class*="topbar"] {
  display: none !important;
}

/* Pastikan html dan body hanya menampilkan print content */
html, body {
  height: auto !important;
  overflow: visible !important;
}
```

Pastikan juga `body` tidak punya `min-height` atau `overflow: hidden` yang mengganggu.

## Cara Uji Coba

1. Jalankan dev server:
   ```bash
   npm run dev
   ```

2. Buka halaman invoice detail:
   ```
   http://localhost:3000/hq/invoice-customer/{id}
   ```

3. Pastikan screen layout muncul normal (tabel, tombol, dll)

4. Klik tombol **Print** atau buka:
   ```
   http://localhost:3000/hq/invoice-customer/{id}?print=1
   ```

5. Di dialog print browser, pilih:
   - **Layout:** Portrait
   - **Paper size:** A4
   - **Margins:** None (atau Minimum)
   - **Check:** Background graphics

6. Pratinjau — pastikan:
   - Tidak ada header/nav aplikasi yang muncul
   - Tabel tidak terpotong di margin kanan
   - Status badge tetap berwarna (biru untuk "sent", hijau untuk "accepted")
   - Halaman 1 dan 2 terpisah rapi
