### 2.1 — Database Schema (Migration 026)
**File:** `supabase/migrations/026_crm_tables.sql`

**Tabel baru:**

```sql
-- CRM Contacts (pelanggan)
crm_contacts:
  id UUID PK
  tenant_id UUID FK → tenants
  name TEXT
  phone TEXT (UNIQUE per tenant)
  email TEXT
  company TEXT
  source TEXT ('work_order', 'manual', 'whatsapp')
  tags TEXT[]
  total_orders INTEGER DEFAULT 0
  last_order_date TIMESTAMPTZ
  notes TEXT
  created_at, updated_at

-- CRM Conversations (thread per kontak)
crm_conversations:
  id UUID PK
  tenant_id UUID FK → tenants
  contact_id UUID FK → crm_contacts
  channel TEXT ('whatsapp', 'chat', 'email')
  status TEXT ('open', 'pending', 'resolved', 'closed')
  assigned_to UUID FK → profiles
  last_message_at TIMESTAMPTZ
  created_at, updated_at

-- CRM Messages (pesan individual)
crm_messages:
  id UUID PK
  conversation_id UUID FK → crm_conversations
  contact_id UUID FK → crm_contacts
  sender_type TEXT ('customer', 'agent', 'system')
  sender_id UUID (agent = profile.id, customer = null)
  channel TEXT ('whatsapp', 'chat')
  content TEXT
  media_url TEXT
  whatsapp_sid TEXT (jika dari Twilio)
  direction TEXT ('inbound', 'outbound')
  status TEXT ('sent', 'delivered', 'read', 'failed')
  created_at

-- CRM Pipeline (deal tracking)
crm_deals:
  id UUID PK
  tenant_id UUID FK → tenants
  contact_id UUID FK → crm_contacts
  wo_id UUID FK → work_orders (nullable)
  stage TEXT ('lead', 'quoted', 'negotiation', 'won', 'lost')
  value NUMERIC
  probability INTEGER
  expected_close DATE
  notes TEXT
  created_at, updated_at
```

### 2.2 — WhatsApp Webhook API
**File:** `app/api/whatsapp/webhook/route.ts` (sudah ada, perlu diperbaiki)

**Logic:**
1. Terima incoming message dari Twilio
2. Parse phone number → cari di `crm_contacts`
3. Jika kontak baru → auto-create contact
4. Cari/create `crm_conversation`
5. Insert `crm_message` (direction: inbound)
6. Jika ada WO aktif dari customer → attach ke conversation
7. Return 200 OK ke Twilio
