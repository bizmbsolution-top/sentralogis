# Rencana Kerja — 22 Mei 2026

## 🎯 Goal
Bangun **WhatsApp Bot Gateway** untuk CRM multi-tenant Sentralogis. 1 nomor WA Business melayani semua tenant dengan routing otomatis berdasarkan `tenants.id` (UUID).

---

## 📐 Arsitektur yang Disepakati

```
Customer scan QR / klik link Tenant A
         │
         ▼
wa.me/628123456789?text=UUID:{tenant_id}
         │
         ▼
Webhook: /api/whatsapp/webhook
  ├─ Parse "UUID:{tenant_id}" → lookup tenant
  ├─ Create crm_lead (auto-link ke tenant)
  ├─ Reply: Interactive Menu (branding Tenant A)
  └─ Notify CS Tenant A
```

### Routing Key
- **Langsung pakai `tenants.id`** (UUID) — tidak perlu kolom `wa_uuid` baru
- Format pesan: `UUID:{tenant_id}` (auto-filled via wa.me link)
- Short URL: `sentralogis.com/wa/{tenant_id}` → redirect ke wa.me link

## 📋 TASK 1: Database Migration (Pagi — 1 jam)

### 1.1 — Migration 027: CRM Tables
**File:** `supabase/migrations/027_crm_tables.sql`

#### `crm_leads` — Opportunity tracking
```sql
crm_leads:
  id UUID PK DEFAULT gen_random_uuid()
  tenant_id UUID FK → tenants (NOT NULL)
  phone TEXT NOT NULL
  name TEXT
  source TEXT DEFAULT 'whatsapp'
  wa_uuid TEXT
  status TEXT DEFAULT 'new'
  category TEXT
  sub_category TEXT
  lost_reason TEXT
  wo_id UUID FK → work_orders
  assigned_to UUID FK → profiles
  first_message TEXT
  last_message_at TIMESTAMPTZ
  created_at, updated_at
```

#### `crm_messages` — Semua percakapan
```sql
crm_messages:
  id UUID PK DEFAULT gen_random_uuid()
  lead_id UUID FK → crm_leads
  direction TEXT NOT NULL
  content TEXT
  media_url TEXT
  twilio_sid TEXT
  meta_wa_id TEXT
  status TEXT DEFAULT 'sent'
  created_at TIMESTAMPTZ DEFAULT NOW()
```

#### `crm_notes` — Internal notes CS
```sql
crm_notes:
  id UUID PK DEFAULT gen_random_uuid()
  lead_id UUID FK → crm_leads
  agent_id UUID FK → profiles
  note TEXT NOT NULL
  created_at TIMESTAMPTZ DEFAULT NOW()
```

#### `crm_activity_log` — Audit trail
```sql
crm_activity_log:
  id UUID PK DEFAULT gen_random_uuid()
  lead_id UUID FK → crm_leads
  tenant_id UUID FK → tenants
  agent_id UUID FK → profiles
  action TEXT NOT NULL
  details JSONB
  created_at TIMESTAMPTZ DEFAULT NOW()
```

### 1.2 — RLS Policies

- Owner bisa akses semua lead
