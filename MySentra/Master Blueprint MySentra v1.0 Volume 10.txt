# Chapter 19

# AI Model Strategy

Saya tidak ingin tergantung pada satu model AI.

Gunakan **Model Gateway**.

```text
MySentra
     │
     ▼
 SentraMind Gateway
     │
 ┌───┼───────────────┐
 │   │               │
 ▼   ▼               ▼
OpenAI  Gemini  Anthropic
```

Setiap kemampuan bisa menggunakan model yang paling sesuai.

| Kebutuhan              | Model yang Cocok           |
| ---------------------- | -------------------------- |
| Percakapan operasional | OpenAI                     |
| OCR + Vision           | OpenAI / Gemini            |
| Dokumen panjang        | Anthropic                  |
| Ringkasan laporan      | Model yang paling ekonomis |

Dengan gateway, Anda tidak terkunci pada satu vendor AI.
