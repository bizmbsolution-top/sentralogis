# Rencana Kerja SBU Warehouse - 23 Mei 2026

Dokumen ini adalah acuan daftar tugas (Task List) harian untuk memulai eksekusi pengembangan SBU Warehouse (Tahap 1), menyelaraskan konsep Warehouse dengan arsitektur Trucking yang sudah berjalan.

## 🎯 Fokus Utama Besok (Fase 1: Fondasi WMS & Inbound)
Fokus kita besok adalah menyambungkan benang merah dari **HQ (Pembuatan WO Warehouse)** sampai ke **SBU Warehouse (Penerimaan Task)**, dengan menyiapkan fondasi database-nya terlebih dahulu.

---

### 📋 Task 1: Eksekusi Skema Database WMS (Pagi)
Membuat skrip SQL dan mengeksekusinya di Supabase untuk struktur data operasional Gudang:
- `[ ]` **Master Data Gudang:** Buat tabel `md_warehouses` (Daftar Gedung) dan `md_warehouse_locations` (Daftar Area, Zona, Rak/Bin).
- `[ ]` **Master Data SKU:** Buat tabel `md_product_skus` untuk mencatat spesifikasi komoditas (dimensi, berat, FEFO/FIFO rule).
- `[ ]` **Operasional WMS:** Buat tabel `wh_tasks` (sebagai pengganti `job_orders` khusus SBU Warehouse, menyimpan task Receiving/Picking) dan tabel `wh_inventory` (untuk melacak *Inventory_ID* dan koordinat stok aktual).
- `[ ]` **RLS Policies:** Memastikan semua tabel WMS menggunakan *Row Level Security* berbasis `tenant_id`.

### 📋 Task 2: Integrasi Form Pembuatan WO di HQ (Siang)
Memperbarui sistem pembuatan Work Order di level HQ/CS agar bisa melempar pesanan ke SBU Warehouse:
- `[ ]` Buka file `app/(dashboard)/hq/work-orders/components/CreateWOForm.tsx`.
- `[ ]` Tambahkan UI / Form khusus saat SBU `WAREHOUSE` dipilih (mirip dengan form `AddTruckingItemModal.tsx`).
- `[ ]` Tambahkan kolom input untuk tipe task gudang: **INBOUND** (Titip Simpan) atau **OUTBOUND** (Keluarkan Barang).
- `[ ]` Pastikan JSON data spesifik gudang tersimpan rapi di dalam kolom `item_data` pada tabel `wo_items`.

### 📋 Task 3: Pembangunan Dashboard SBU Warehouse Manager (Sore)
Membuat antarmuka awal untuk Manajer SBU Warehouse menerima tugas dari HQ:
- `[ ]` Scaffold layout halaman di `/sbu/warehouse/work-orders`.
- `[ ]` Buat Query Supabase untuk menarik data `wo_items` yang memiliki `sbu_type = 'WAREHOUSE'` dan menampilkannya dalam bentuk tabel interaktif.
- `[ ]` Buat UI/UX untuk detail WO Item WMS, menampilkan instruksi barang apa saja yang akan masuk (Inbound) atau keluar (Outbound).

---

## 🛠 Aturan Pengerjaan & Code Guideline (Review)
1. **No Hallucination:** Tetap mengikuti pakem Supabase client `process.env.NEXT_PUBLIC_SUPABASE_URL` dari `.env.local` saat menarik data.
2. **Reusability:** Jika memungkinkan, gunakan *UI Component* yang sudah ada di modul Trucking (seperti `Card`, `Badge` status, `Table` styling) agar tampilan konsisten dan pengerjaan lebih cepat.
3. **Database First:** Semua fitur UI baru tidak boleh dibuat sebelum skema tabel dan kolomnya benar-benar diuji via SQL Editor.
