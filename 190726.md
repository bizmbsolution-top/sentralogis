## Arsitektur Data

### 3 Tabel Baru

```sql
-- 1. KONSOLIDASI (1 baris per vessel/voyage)
fw_consolidations {
  id              UUID PK,
  tenant_id       UUID,
  consol_number   TEXT UNIQUE(tenant_id),  -- otomatis: FWD-YYYYMM-XXX
  shipping_line_id UUID,                   -- md_entities vendor_type='SHIPPING_LINE'
  shipping_line_name TEXT,
  vessel_name     TEXT,
  voyage_number   TEXT,
  origin_port     TEXT,                     -- "Tanjung Perak, Surabaya"
  destination_port TEXT,                    -- "Makassar"
  etd             DATE,
  eta             DATE,
  consol_warehouse_origin_id UUID,         -- md_warehouses type='CONSOL'
  consol_warehouse_origin_name TEXT,
  consol_warehouse_destination_id UUID,
  consol_warehouse_destination_name TEXT,
  status          TEXT DEFAULT 'open',      -- open → stuffing → shipped → arrived → deconsol_done → closed
  created_at      TIMESTAMPTZ DEFAULT NOW(),
  updated_at      TIMESTAMPTZ DEFAULT NOW()
}

-- 2. KONTAINER DALAM KONSOLIDASI (1 baris per container)
fw_container_assignments {
  id                UUID PK,
  tenant_id         UUID,
  consolidation_id  UUID FK → fw_consolidations,
  container_number  TEXT NOT NULL,
  container_type    TEXT NOT NULL,          -- 20GP, 40GP, 40HC, 20RF, dll
  seal_number       TEXT,
  bl_number         TEXT,                   -- MBL (Master BL)
  max_volume_cbm    NUMERIC,               -- kapasitas container
  status            TEXT DEFAULT 'empty',   -- empty → stuffed → shipped → arrived → deconsoled → returned
  created_at        TIMESTAMPTZ DEFAULT NOW(),
  updated_at        TIMESTAMPTZ DEFAULT NOW()
}

-- 3. CARGO PER KONTAINER (1 baris per cargo owner per container)
fw_container_items {
  id                    UUID PK,
  tenant_id             UUID,
  container_assignment_id UUID FK → fw_container_assignments,
  wo_item_id            UUID FK → wo_items,
  -- ⬇ Cargo Owner (override wo_item.customer_id untuk groupage)
  cargo_owner_name      TEXT,               -- "PT Elektronik Jaya"
  consignee_name        TEXT,               -- "Toko Makmur" (penerima di tujuan)
  consignee_address     TEXT,
  consignee_phone       TEXT,
  -- ⬇ Cargo Specs
  volume_cbm            NUMERIC,
  gross_weight_kg       NUMERIC,
  packages              INTEGER,
  package_type          TEXT,
  commodity             TEXT,
  description           TEXT,
  -- ⬇ Logistics
  is_self_delivery      BOOLEAN DEFAULT false,  -- true = barang diantar sendiri ke gudang
  goods_received_at     TIMESTAMPTZ,
  delivery_type         TEXT DEFAULT 'port_to_port',  -- port_to_port | port_to_door
  delivery_address      TEXT,               -- alamat tujuan (jika port_to_door)
  delivery_contact      TEXT,
  delivery_phone        TEXT,
  delivery_jo_id        UUID,               -- JO Trucking delivery (diisi saat deconsol)
  is_deconsoled         BOOLEAN DEFAULT false,
  deconsoled_at         TIMESTAMPTZ,
  tracking_token        TEXT UNIQUE,        -- untuk cargo owner tracking
  created_at            TIMESTAMPTZ DEFAULT NOW(),
  updated_at            TIMESTAMPTZ DEFAULT NOW()
}
```

## Workflow & Status Flow

### Status WO Forwarding

```
pending → gudang_terima → stuffing → shipped → arrived → deconsol → selesai
```

### Status Konsolidasi

```
open ─→ stuffing ─→ shipped ─→ arrived ─→ deconsol_done ─→ closed
```

### Status Container

```
empty ─→ stuffed ─→ shipped ─→ arrived ─→ deconsoled ─→ returned
```

### Status Cargo Item

```
pending ─→ received ─→ stuffed ─→ shipped ─→ arrived ─→ deconsoled ─→ (delivered)
```

## Skenario Bisnis

### FCL Direct (1 WO = 1 customer = 1+ container)

```
WO (Customer A) — D2D
└── WO Item: Container MRTU111, 20GP
      ├── JO 1: Pickup Trucking (Door A → Gudang Consol SBY)
      ├── JO 2: Ocean Freight (SBY → MKS — via fw_container_assignments)
      └── JO 3: Delivery Trucking (Gudang MKS → Door A)
```

### LCL Groupage (1 WO = 1 forwarder = N cargo owners)

```
WO (Forwarder X) — 23 CBM, self-delivery
└── WO Item: "Groupage LCL"
      ├── JO: Ocean Freight (via container MRTU444)
      └── fw_container_items breakdown:
            ├── PT Elektronik (5 CBM) → Toko Makmur     [delivery: port_to_door]
            ├── PT Furniture (10 CBM) → CV Mebel Indah  [delivery: port_to_door]
            └── PT Makanan (8 CBM) → UD Camilan         [delivery: port_to_port]
```

### Hybrid Delivery per Cargo Item

| Delivery Type | Flow |
|---------------|------|
| `port_to_port` | Barang berhenti di gudang consol tujuan → cargo owner ambil sendiri |
| `port_to_door` | Otomatis create JO Delivery Trucking saat deconsol → diantar ke alamat |
