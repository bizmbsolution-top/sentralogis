## 3. Repacking, Bundling & Kitting
**Latar:** Fitur baru untuk mengubah unit produk di gudang:
- **Repacking:** Satu SKU besar dipecah jadi SKU kecil (misal: 1 karton → 10 pcs)
- **Bundling:** Beberapa SKU digabung jadi 1 SKU bundle baru
- **Kitting:** Satu set item (kit) diambil dari stok untuk memenuhi work order

**Todo (Research & Design):**
- [ ] Identifikasi tabel yang diperlukan:
  - `wh_repacking_orders` — header repacking/bundling/kitting task
  - `wh_repacking_items` — source items (in) dan result items (out)
  - Relasi ke `wh_inventory` untuk source consumption + result creation
- [ ] Tentukan workflow:
  - **Repacking:** Source SKU di-deduct dari inventory, result SKU baru di-insert
  - **Bundling:** Multiple source SKU di-deduct, 1 bundle SKU di-insert
  - **Kitting:** Multiple source SKU di-deduct, terikat ke work order item
- [ ] Desain status flow: `CREATED → IN_PROGRESS → COMPLETED → CANCELLED`
- [ ] Implementasi halaman SBU: list + create + detail
- [ ] Implementasi portal task untuk eksekusi picking source items
- [ ] Audit trail via `wh_inventory_movements`
