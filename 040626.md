# Rencana Pekerjaan: 04 Juni 2026 (040626)

## 1. Perbaikan UI/UX Work Orders (`/hq/work-orders`)
**Masalah**: 
Tampilan daftar Work Orders saat ini masih ambigu. Sulit untuk langsung membedakan mana Work Order yang ditujukan untuk operasional Trucking, Warehouse, atau divisi SBU lainnya.

**Target Perbaikan**:
- Menambahkan indikator visual (seperti *badge* atau kolom khusus) pada tabel Work Order untuk memperjelas `SBU Type` (misal: label warna biru untuk `TRUCKING`, hijau untuk `WAREHOUSE`).
- Mempertimbangkan penambahan filter atau *tabs* untuk menyortir Work Order berdasarkan SBU terkait.
- Memastikan detail Work Order secara tegas menampilkan tipe layanan yang dipesan.

## 2. Perbaikan Bug Row-Level Security (RLS) pada Fitur Staff (`/tenant/staff`)
**Masalah**: 
Ketika akun dari *Tenant* baru mencoba menambahkan staff dan mengatur hak akses mereka (Manage SBU Staff), muncul error database dari Supabase: 
`ERROR new row violates row-level security policy for table "tenant_sbus"`.

**Target Perbaikan**:
- Mengecek dan menyesuaikan *Policy* (RLS) pada tabel `tenant_sbus` di Supabase. Kemungkinan *policy* untuk operasi `INSERT` saat ini memblokir akses pengguna baru karena tidak mendeteksi relasi *tenant* dengan benar.
- Memastikan bahwa *payload* saat fungsi `INSERT` dijalankan dari *frontend* (di *page* `/tenant/staff`) telah menyertakan `tenant_id` atau `user_id` yang cocok dengan kebijakan keamanan.
- Menguji alur pembuatan staff menggunakan akun *Tenant* baru secara menyeluruh (dari pembuatan hingga *assignment* SBU).
