# 31. Smart Workspace

The Sentralogis Copilot **Smart Workspace** (`/copilot`) represents the next generation of operational interfaces for the SentraForge Enterprise platform.

## Objective
To centralize 80% of daily operations (Customer Service, Dispatch, Ground Staff, Supervisors) into a single, intuitive interface, reducing cognitive load and the need to navigate across disparate module pages.

## Design Aesthetic
The interface draws inspiration from modern productivity tools (Linear, Cursor, Notion AI) emphasizing:
- Minimalist design.
- High information density without clutter.
- Fast, responsive interactions.
- Avoidance of traditional "enterprise ERP" complexity.

## Core Capabilities
1. **Conversational Command**: Natural language input, pasting WhatsApp strings, or dragging/dropping files.
2. **Contextual Awareness**: The sidebar maintains execution history and active entities in focus.
3. **Execution Previews**: When an action is deduced, a rich `ActionProposalCard` is rendered for user review.
4. **Explainability**: Every action guarantees full transparency on *why* it was generated, adhering to AI safety rules.
